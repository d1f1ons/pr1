# Архитектура ОС

## 1. Состав модулей

- `shell.py` — командная оболочка, читает команды пользователя и отображает результат.
- `syscalls.py` — системные вызовы, единый интерфейс между оболочкой и ядром.
- `kernel.py` — ядро, обрабатывает вызовы, проверяет права и координирует подсистемы.
- `scheduler.py` — планировщик, управляет состоянием процессов и очередью выполнения.
- `memory.py` — подсистема управления оперативной памятью.
- `fs.py` — файловая система, управляет виртуальным файловым деревом и каталогами.
- `auth.py` — подсистема аутентификации, авторизации и проверки прав доступа.
- `db.py` — абстракция работы с СУБД SQLite для долговременного хранения[cite: 3].

## 2. Системные вызовы

### Спецификация API системных вызовов
- `sys_login(login: str, password: str) -> bool` — авторизация пользователя[cite: 3].
- `sys_logout() -> bool` — завершение текущей сессии[cite: 3].
- `sys_whoami() -> str` — получение имени текущего пользователя[cite: 3].
- `sys_create_file(path: str, content: str) -> int` — создание файла (возвращает id файла)[cite: 3].
- `sys_read_file(path: str) -> str` — чтение содержимого файла[cite: 3].
- `sys_delete_file(path: str) -> bool` — удаление файла[cite: 3].
- `sys_list_files(path: str) -> list` — получение списка файлов в каталоге[cite: 3].
- `sys_exec(name: str) -> int` — запуск нового процесса (возвращает PID)[cite: 3].
- `sys_ps() -> list` — получение списка активных процессов[cite: 3].
- `sys_kill(pid: int) -> bool` — завершение процесса по его PID[cite: 3].
- `sys_mem_alloc(size: int) -> int` — выделение блока памяти заданной величины[cite: 3].
- `sys_logs(limit: int) -> list` — получение последних записей из системного журнала[cite: 3].
- `sys_shutdown() -> bool` — корректная остановка системы[cite: 3].

### Контракты функций

#### 1. `sys_login`
- **Предварительное условие:** Пользователь с указанным логином существует в базе данных[cite: 3].
- **Постусловие:** Возвращает `True` при совпадении хэшей паролей, иначе `False`[cite: 3].
- **Побочный эффект:** В случае успеха меняется текущий контекст пользователя; фиксация попытки входа в журнале `syscalls_log`[cite: 3].

#### 2. `sys_create_file`
- **Предварительное условие:** Пользователь авторизован и имеет права на запись в данный каталог[cite: 3].
- **Постусловие:** Создана новая запись в таблице `files`, функция возвращает уникальный `id` файла[cite: 3].
- **Побочный эффект:** Изменение структуры базы данных (таблица `files`); создание записи в `syscalls_log`[cite: 3].

#### 3. `sys_exec`
- **Предварительное условие:** Пользователь авторизован; запрашиваемый исполняемый модуль существует в системе[cite: 3].
- **Постусловие:** В реестр процессов добавлена запись с новым `PID`, статус процесса установлен в `running`[cite: 3].
- **Побочный эффект:** Выделение ресурсов подсистемой памяти; запись события запуска в `syscalls_log`[cite: 3].
