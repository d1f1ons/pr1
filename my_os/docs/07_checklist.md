# Чек-лист проверки функциональности StudyOS[cite: 109]

## Оболочка (Shell)[cite: 109]
- [x] Команда `help` выводит список команд[cite: 109].
- [x] Команда `whoami` возвращает текущего пользователя[cite: 109].
- [x] Команда `login` запрашивает логин и пароль[cite: 109].
- [x] Команда `mem` показывает состояние памяти[cite: 109].
- [x] Команда `logs` выводит записи журнала[cite: 109].
- [x] Команда `exit` завершает работу[cite: 109].

## Файловая система (FS)[cite: 109]
- [x] Команда `create` создает файл[cite: 109].
- [x] Команда `cat` читает файл[cite: 109].
- [x] Команда `ls` выводит список файлов[cite: 109].
- [x] Команда `delete` удаляет файл[cite: 109].
- [x] Повторное создание файла с тем же путем возвращает ошибку[cite: 109].
- [x] Обычный пользователь не может удалить чужой файл[cite: 109].

## Планировщик (Scheduler)[cite: 109]
- [x] Команда `run` запускает процесс[cite: 109].
- [x] Команда `ps` выводит список процессов[cite: 109].
- [x] Команда `kill` завершает процесс[cite: 109].
- [x] После завершения процесса память освобождается[cite: 109].
- [x] Обычный пользователь не может завершить чужой процесс[cite: 109].

## Пользователи и аутентификация[cite: 109]
- [x] Регистрация нового пользователя с ролью `user`[cite: 109].
- [x] Пустой или неверный пароль отклоняется[cite: 109].
- [x] Смена текущего пользователя при логине[cite: 109].

## База данных (БД)[cite: 109]
- [x] Таблица `users` заполняется[cite: 109].
- [x] Таблица `files` заполняется[cite: 109].
- [x] Таблица `processes` заполняется[cite: 109].
- [x] Таблица `syscalls_log` заполняется[cite: 109].
- [x] Таблица `memory_state` обновляется[cite: 109].
