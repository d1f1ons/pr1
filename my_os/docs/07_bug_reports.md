# Баг-репорты[cite: 115]

## BUG-01: Попытка создать дубликат файла[cite: 115]
**Серьёзность:** средняя[cite: 115]
**Приоритет:** средний[cite: 115]
**Статус:** закрыт (не воспроизводится)[cite: 115]

**Шаги воспроизведения:**[cite: 115]
1. Создать файл `/dup.txt` с содержимым `"a"`[cite: 115].
2. Повторно создать файл `/dup.txt` с содержимым `"b"`[cite: 115].

**Ожидаемый результат:** Второй вызов возвращает `-1`[cite: 115].
**Фактический результат:** Второй вызов возвращает `-1`[cite: 115].
**Причина:** В `fs.create_file` выполняется предварительная проверка на существование файла[cite: 115].
**Решение:** Дефект не обнаружен, поведение системы полностью корректное[cite: 115].
