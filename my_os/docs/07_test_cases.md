# Тест-кейсы

## Модуль db.py[cite: 106]

### TC-01: Создание записи[cite: 106]
- **Шаги:**
  1. Вызвать `execute_insert('users', {'login': 'tc01', 'password_hash': 'x', 'role': 'user'})`[cite: 106].
  2. Проверить возвращенное значение[cite: 106].
- **Ожидаемый результат:** Число > 0[cite: 106].
- **Фактический результат:** Возвращен ID записи > 0.
- **Статус:** Пройден.

### TC-02: Выборка записи по условию[cite: 106]
- **Шаги:**
  1. Вызвать `execute_select('users', {'login': 'tc01'})`[cite: 106].
  2. Проверить состав списка[cite: 106].
- **Ожидаемый результат:** Список из 1 записи[cite: 106].
- **Фактический результат:** Список из 1 записи.
- **Статус:** Пройден.

### TC-03: Обновление записи[cite: 106]
- **Шаги:**
  1. Вызвать `execute_update('users', {'role': 'admin'}, {'login': 'tc01'})`[cite: 106].
  2. Проверить `execute_select('users', {'login': 'tc01'})`[cite: 106].
- **Ожидаемый результат:** `role == 'admin'`[cite: 106].
- **Фактический результат:** Поле `role` равно `admin`.
- **Статус:** Пройден.

### TC-04: Удаление записи[cite: 106]
- **Шаги:**
  1. Вызвать `execute_delete('users', {'login': 'tc01'})`[cite: 106].
  2. Вызвать `execute_select('users', {'login': 'tc01'})`[cite: 106].
- **Ожидаемый результат:** Пустой список[cite: 106].
- **Фактический результат:** Список пуст `[]`.
- **Статус:** Пройден.

## Модуль kernel.py[cite: 107]

### TC-05: Инкремент PID
- **Шаги:** Вызвать `allocate_pid()` дважды.
- **Ожидаемый результат:** Второй PID на 1 больше первого.
- **Фактический результат:** PID увеличился ровно на 1.
- **Статус:** Пройден.

### TC-06: Выделение памяти
- **Шаги:** Вызвать `allocate_memory(100)`.
- **Ожидаемый результат:** Возвращено `True`, в `memory_info()['used']` записано 100.
- **Фактический результат:** Память выделена.
- **Статус:** Пройден.

### TC-07: Освобождение памяти
- **Шаги:** Вызвать `allocate_memory(100)`, затем `free_memory(100)`.
- **Ожидаемый результат:** `used` уменьшилось на 100.
- **Фактический результат:** Объём памяти вернулся к 0.
- **Статус:** Пройден.

## Модуль auth.py[cite: 108]

### TC-08: Хэширование пароля[cite: 108]
- **Шаги:** Вызвать `hash_password("secret")`[cite: 108].
- **Ожидаемый результат:** Длина строки 64 символа, не равна `"secret"`[cite: 108].
- **Фактический результат:** SHA-256 хэш длиной 64 символа.

- **Фактический результат:** `None`.
