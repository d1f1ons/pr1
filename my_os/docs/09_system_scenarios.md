# Системные сценарии

## SS-01: Первый запуск ОС
**Предусловие:** файл db/os.sqlite отсутствует, все модули src готовы[cite: 4].
**Шаги:**
1. Удалить файл db/os.sqlite[cite: 5].
2. Запустить python src/db.py[cite: 5].
3. Убедиться, что файл создан[cite: 5].
4. Открыть его через SQLite Viewer[cite: 5].
5. Проверить наличие таблиц: users, processes, files, syscalls_log, memory_state, roles[cite: 5].
6. Проверить, что таблица roles содержит три записи: admin, user, guest[cite: 5].
**Ожидаемый результат:** база создана, все таблицы присутствуют, роли заполнены[cite: 5].
**Постусловие:** система готова к первому запуску[cite: 5].

## SS-02: Работа администратора
**Предусловие:** пользователь admin зарегистрирован с ролью admin, пароль admin123[cite: 5].
**Шаги:**
1. Запустить python -m src.shell[cite: 5].
2. Войти как admin[cite: 5].
3. Создать файл /ss02_a.txt с содержимым "first file"[cite: 5].
4. Создать файл /ss02_b.txt с содержимым "second file"[cite: 5].
5. Прочитать файл /ss02_a.txt[cite: 5].
6. Запустить процесс app1[cite: 5].
7. Запустить процесс app2[cite: 5].
8. Вывести список процессов[cite: 5].
9. Завершить процесс app1[cite: 5].
10. Проверить состояние памяти[cite: 5].
11. Выйти[cite: 5].
**Ожидаемый результат:** все команды выполнены, файлы созданы, процессы запущены и завершены, память освобождена, журнал заполнен[cite: 5].

## SS-03: Работа обычного пользователя
**Предусловие:** пользователь user зарегистрирован с ролью user, пароль user1234. Файл /ss02_a.txt принадлежит admin[cite: 5].
**Шаги:**

2. Войти как user[cite: 5].
3. Создать свой файл /ss03_my.txt[cite: 5].
4. Попробовать удалить файл /ss02_a.txt, принадлежащий admin[cite: 5].
5. Запустить свой процесс user_app[cite: 5].
6. Попробовать завершить процесс admin[cite: 5].
7. Выйти[cite: 5].
**Ожидаемый результат:** свои действия разрешены, чужие запрещены, отказы в журнале со статусом DENIED.

## SS-04: Восстановление после ошибок
**Предусловие:** система работает, пользователь admin зарегистрирован.
**Шаги:**
1. Запустить оболочку.
2. Попробовать войти с неверным паролем.
3. Войти с правильным паролем[cite: 6].
4. Попробовать прочитать несуществующий файл[cite: 6].
5. Попробовать завершить несуществующий процесс[cite: 6].
6. Попробовать создать дубликат файла[cite: 6].
7. Убедиться, что система продолжает работать[cite: 6].
8. Выйти[cite: 6].
**Ожидаемый результат:** система обрабатывает ошибки без падения, выводит корректные сообщения, продолжает принимать команды[cite: 6].
