# Функциональные тесты

## Модуль fs.py

Функции модуля: create_file, read_file, write_file, delete_file, list_files, get_owner, get_file_info.

### FT-01: create_file создаёт файл
**Предусловие:** файла с указанным путём нет.
**Шаги:** вызвать create_file('/ft01.txt', 'content', 'admin').
**Ожидаемый результат:** возвращено число > 0, в таблице files появилась запись.

### FT-02: create_file отклоняет дубликат
**Предусловие:** файл /ft02.txt уже создан.
**Шаги:** повторно вызвать create_file('/ft02.txt', 'other', 'admin').
**Ожидаемый результат:** возвращено -1.

### FT-03: read_file возвращает содержимое
**Предусловие:** файл /ft03.txt с содержимым 'hello'.
**Шаги:** вызвать read_file('/ft03.txt').
**Ожидаемый результат:** возвращена строка 'hello'.

### FT-04: read_file возвращает пустую строку для несуществующего файла
**Предусловие:** файла /missing.txt нет.
**Шаги:** вызвать read_file('/missing.txt').
**Ожидаемый результат:** возвращена пустая строка.

### FT-05: write_file обновляет содержимое
**Предусловие:** файл /ft05.txt с содержимым 'old'.
**Шаги:** вызвать write_file('/ft05.txt', 'new'), затем read_file('/ft05.txt').
**Ожидаемый результат:** возвращена строка 'new'.

### FT-06: delete_file удаляет файл
**Предусловие:** файл /ft06.txt создан.
**Шаги:** вызвать delete_file('/ft06.txt'), затем read_file('/ft06.txt').
**Ожидаемый результат:** read_file возвращает пустую строку.

### FT-07: list_files возвращает список по профилю
**Предусловие:** созданы файлы /ft07_a.txt и /ft07_b.txt.
**Шаги:** вызвать list_files('/ft07').
**Ожидаемый результат:** список содержит оба файла.

### FT-08: get_owner возвращает владельца
**Предусловие:** файл /ft08.txt создан с владельцем 'admin'.
**Шаги:** вызвать get_owner('/ft08.txt').
**Ожидаемый результат:** возвращена строка 'admin'.

### FT-09: get_owner возвращает None для несуществующего файла
**Предусловие:** файла /missing2.txt нет.
**Шаги:** вызвать get_owner('/missing2.txt').
**Ожидаемый результат:** None.

### FT-10: get_file_info возвращает полную информацию
**Предусловие:** файл /ft09.txt создан с владельцем 'admin'.
**Шаги:** вызвать get_file_info('/ft09.txt').
**Ожидаемый результат:** словарь с полями path, owner и др.

## Модуль scheduler.py

Функции модуля: create_process, list_processes, get_process, terminate_process, schedule_round_robin, process_count.

### FT-11: create_process создаёт процесс
**Предусловие:** памяти достаточно.
**Шаги:** вызвать create_process('ft_app', 'admin', 10).
**Ожидаемый результат:** возвращён PID > 0, в таблице processes появилась запись.

### FT-12: create_process отклоняет процесс при переполнении памяти
**Предусловие:** памяти недостаточно.
**Шаги:** вызвать create_process('huge', 'admin', 5000).
**Ожидаемый результат:** возвращено -1.

### FT-13: list_processes возвращает все процессы
**Предусловие:** созданы два процесса.
**Шаги:** вызвать list_processes.
**Ожидаемый результат:** список из двух записей.

### FT-14: get_process находит процесс по PID
**Предусловие:** процесс с PID создан.
**Шаги:** вызвать get_process(pid).
**Ожидаемый результат:** словарь с полями процесса.

### FT-15: get_process возвращает None для несуществующего PID
**Предусловие:** PID 99999 не существует.
**Шаги:** вызвать get_process(99999).
**Ожидаемый результат:** None.

### FT-16: terminate_process завершает процесс и освобождает память
**Предусловие:** процесс с PID создан, память выделена.
**Шаги:** запомнить memory_used, вызвать terminate_process(pid).
**Ожидаемый результат:** True, память уменьшилась на размер процесса.

### FT-17: terminate_process возвращает False для несуществующего PID
**Предусловие:** PID 99999 не существует.
**Шаги:** вызвать terminate_process(99999).
**Ожидаемый результат:** False.

### FT-18: schedule_round_robin выбирает процесс
**Предусловие:** созданы два процесса в состоянии ready.
**Шаги:** вызвать schedule_round_robin.
**Ожидаемый результат:** возвращён процесс в состоянии running.

### FT-19: process_count возвращает количество процессов
**Предусловие:** созданы три процесса.
**Шаги:** вызвать process_count.
**Ожидаемый результат:** 3.
