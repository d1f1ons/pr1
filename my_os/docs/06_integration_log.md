# Журнал интеграции и отладки StudyOS

## Обработка ошибок в сквозных сценариях

### 1. Несуществующий логин
- **Сценарий:** Попытка входа от имени несуществующего пользователя `nobody`.
- **Ввод:** `login` -> Логин: `nobody` -> Пароль: `anything`
- **Ожидаемый результат:** Сообщение «Ошибка входа», система продолжает работу.
- **Фактический результат:** `guest@studyos:~$` вывел «Ошибка входа», статус системного вызова в `syscalls_log` — `DENIED`.
- **Статус:** Пройдено успешно.

### 2. Чтение несуществующего файла
- **Сценарий:** Вызов команды `cat` для отсутствующего файла.
- **Ввод:** `cat /missing.txt`
- **Ожидаемый результат:** Сообщение «(файл пуст или не существует)».
- **Фактический результат:** Система вербозно уведомила об отсутствии файла, сбоя оболочки не произошло.
- **Статус:** Пройдено успешно.

### 3. Завершение несуществующего процесса
- **Сценарий:** Вызов команды `kill` с несуществующим `PID=99999`.
- **Ввод:** `kill 99999`
- **Ожидаемый результат:** Сообщение «Не удалось завершить процесс 99999».
- **Фактический результат:** Сообщение выведено, статус системного вызова — `NOT_FOUND`.
- **Статус:** Пройдено успешно.

### 4. Попытка удаления чужого файла без прав
- **Сценарий:** Удаление файла `/admin_file.txt` от имени пользователя `user`.
- **Ввод:** `delete /admin_file.txt` (при текущем пользователе `user`)
- **Ожидаемый результат:** Отказ в доступе («Нет прав на удаление»).
- **Фактический результат:** Операция заблокирована модулем `check_permission`, статус в логах — `DENIED`.
- **Статус:** Пройдено успешно.
