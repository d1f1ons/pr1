# Баг-репорты (день 8)

## BUG-08-01: Память не увеличивается при создании процесса
**Серьёзность:** высокая
**Приоритет:** высокий
**Статус:** закрыт (не воспроизводится)
**Шаги воспроизведения:**
1. Запомнить kernel_instance.memory_used.
2. Создать процесс через sys_exec.
3. Сравнить memory_used.
**Ожидаемый результат:** memory_used увеличивается.
**Фактический результат:** увеличивается.
**Причина:** дефектов не обнаружено, поведение корректное.
