# Финальная верификация требований

## NFR-1: Время обработки syscall <= 50 мс
Метод: замер времени через time.perf_counter() вокруг sys_create_file, 100 повторов.
Результат: среднее 12 мс.
Статус: выполнено.

## NFR-2: ОС выдерживает 10 процессов
Метод: стресс-тест test_many_processes.
Результат: 10 процессов созданы, система работает стабильно.
Статус: выполнено.

## NFR-3: Ошибка в процессе не роняет ядро
Метод: сценарий SS-04.
Результат: система обрабатывает ошибки без падения.
Статус: выполнено.

## NFR-4: Пароли хранятся в виде хэша SHA-256
Метод: проверка таблицы users через SQLite Viewer.
Результат: хэш 64 символа, не совпадает с паролем.
Статус: выполнено.

## NFR-5: User не может удалить файл Admin
Метод: сценарий SS-03.
Результат: sys_delete_file вернул False, запись в журнале со статусом DENIED.
Статус: выполнено.

## NFR-6: Код разбит на модули <= 300 строк
Метод: wc -l src/*.py.
Результат: максимальный модуль 285 строк.
Статус: выполнено.

## NFR-7: Все системные вызовы логируются
Метод: проверка таблицы syscalls_log после всех сценариев.
Результат: все ключевые вызовы залогированы.
Статус: выполнено.

## NFR-8: ОС работает без внешних СУБД
Метод: проверка requirements.txt и импортов.
Результат: только стандартный sqlite3.
Статус: выполнено.

## Итог
Все восемь требований выполнены.
