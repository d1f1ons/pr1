# Отчёт по учебной практике

## Введение
Учебная практика проходила с __ по __ 20__ года. Тема практики: «Осуществление интеграции программных модулей». Индивидуальное задание: разработка учебной операционной системы с расширенной иерархической файловой системой.
Цель практики - получить навыки проектирования, разработки, интеграции и тестирования программных модулей на примере учебной операционной системы.

## 1. Предметная область
Учебная операционная система StudyOS имитирует работу реальной ОС. Система управляет пользователями, процессами, памятью и файловой системой. Роль диска выполняет база данных SQLite. Файловая система иерархическая: файлы организованы в дерево каталогов, поддерживаются навигация, копирование, перемещение и построение дерева.

## 2. Архитектура системы
Система состоит из восьми модулей:
- db.py - работа с SQLite;
- kernel.py - состояние системы;
- auth.py - аутентификация и права;
- fs.py - иерархическая файловая система;
- scheduler.py - планировщик процессов;
- syscalls.py - системные вызовы;
- shell.py - командная оболочка;
- logger.py - логирование.
Модули связаны однонаправленно: shell вызывает syscalls, syscalls вызывают kernel и подсистемы, подсистемы обращаются к db.

## 3. Реализованные функции
Управление пользователями: регистрация, вход, роли, разграничение прав.
Иерархическая файловая система: mkdir, rmdir, touch, cat, write, rm, rename, copy, move, cd, pwd, ls, tree.
Управление процессами: run, ps, kill.
Управление памятью: выделение, освобождение, контроль лимита.
Журналирование: все системные вызовы записываются в syscalls_log.

 4. Структура базы данных
Таблицы: users, files, processes, syscalls_log, memory_state, roles.
Поле parent_id в таблице files обеспечивает иерархическую структуру.

 5. Тестирование
Проведено модульное, функциональное, интегративное, системное и стресс-тестирование. Всего написано N тестов, все проходят. Проведено четыре системных сценария. Найдено M дефектов, все исправлены или отложены с обоснованием.

 6. Результаты
Система запускается командой `python -m src.shell`. Все команды работают. Дерево каталогов строится корректно. Права доступа разграничены. Журнал заполняется.

 7. Выводы
В ходе практики получены навыки проектирования, разработки, интеграции и тестирования программных модулей. Освоены принципы построения операционных систем, работы с SQLite, написания автоматических тестов, оформления технической документации.
