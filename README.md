

Проект разработан в рамках практического занятия по теме «Определение границ операционной системы и разработка нефункциональных требований».

 `my_os/src/` — исходный код ядра, системных вызовов и командной оболочки
 `my_os/db/` — база данных SQLite (файловая система, процессы, логи)
 `my_os/docs/` — проектная документация в формате Markdown
 `my_os/logs/` — текстовые логи работы системы
